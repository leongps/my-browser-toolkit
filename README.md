This repository contains filters I use to hide unwanted content, reduce distractions, and improve my browsing experience.

## Filters

- Instagram
  - Hide Reels from the sidebar
  - Hide Explore from the sidebar

- Facebook
  - Hide sponsored posts
  - Hide Reels

- YouTube
  - Hide Shorts

## Usage

Open uBlock Origin:

1. Go to **Dashboard**
2. Open **Filter lists**
3. Add the raw URL of the filter list under **Import**
4. Apply changes

You can also copy the filters manually into **My filters**.
