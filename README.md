# BetterNet

A personal collection of filters, userscripts, browser extensions, and tools that make the web cleaner, less distracting, and more pleasant to use.

## 🛡️ uBlock Origin Filters

### BetterNet

My personal uBlock Origin filter list.

Currently includes filters for:

#### Instagram

* Hide Reels from the sidebar
* Hide Explore from the sidebar

#### Facebook

* Hide sponsored posts
* Hide Reels

#### YouTube

* Hide Games / Playables
* Hide unwanted interface elements

### Installation

Import the following URL into **uBlock Origin → Filter lists → Import**:

```text
https://raw.githubusercontent.com/leongps/my-browser-toolkit/main/betternet.txt
```

## 🐒 Userscripts

### Google Search — No Auto-Translate

Prevents Google Search from automatically translating foreign-language search results.

It restores the original page titles and snippets, removes the **Translated by Google** interface, and changes translated Google links back to the original websites.

Requires a userscript manager such as **Tampermonkey**, **Violentmonkey**, or **Greasemonkey**.

**Install**

https://greasyfork.org/scripts/570066-google-search-no-auto-translate

## 🧩 Browser Extensions & Tools

### YouTube No Translation

Prevents YouTube from automatically translating content.

Features include:

* Original video titles
* Original descriptions
* Original audio tracks
* Original thumbnails
* Subtitle language control

**Project**

https://github.com/YouG-o/YouTube-No-Translation

---

### SponsorBlock

Automatically skips sponsored segments inside YouTube videos using community-submitted timestamps.

It can also optionally skip:

* Intros
* Outros
* Self-promotion
* Subscribe reminders
* Other repetitive segments

**Website**

https://sponsor.ajay.app/

---

### SauceNAO Browser Tools

Adds reverse-image-search options that make it easier to search an image across different services.

Useful for finding image sources and performing reverse image searches with services such as SauceNAO and other search engines.

**Tools**

https://saucenao.com/tools/
